# What These Platforms Promised Creators

*Twenty-Two Platforms and Their Promises, Decoded*

A sourced comparison of 22 social platforms that weighs what each one promised creators against what it actually delivers.

**Scoring:** four criteria, each scored 0 to 2, for a total out of 8: a payment program open on public criteria, audience, trend over about twelve months, and model stability in 2026. Automation is not assessed.

**Top of the ranking:** Meta, Reddit, Snapchat and Telegram, tied at 8/8.
